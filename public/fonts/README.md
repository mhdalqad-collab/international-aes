# Website fonts

These are the unchanged WOFF2 files downloaded by `next/font/google` for the
successful Next.js 16.2.6 build of commit e2556fb. They are checked in so GoDaddy
does not need to download or parse Google Fonts responses during a build.

`app/fonts.css` preserves that build's font families, weights, Unicode ranges,
font-display behavior, and fallback metrics. The three original preloaded
subsets are still preloaded in `app/layout.tsx`. File names retain their build
fingerprints; replace the filename if a font file changes.

Families and original sources:

- Geist: https://github.com/google/fonts/tree/main/ofl/geist
- Geist Mono: https://github.com/google/fonts/tree/main/ofl/geistmono
- Noto Sans Arabic: https://github.com/google/fonts/tree/main/ofl/notosansarabic

Each family is distributed under the SIL Open Font License 1.1. The original
copyright notices and license text are in the corresponding OFL files here.
